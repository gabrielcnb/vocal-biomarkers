Sobre o Dataset

Fonte: UCI Machine Learning Repository - Parkinsons Dataset
Amostras: 195 gravações de 31 sujeitos (23 com Parkinson, 8 saudáveis)
Features: 22 biomarcadores vocais extraídos de fonações sustentadas
Distribuição: 147 amostras PD (75.4%) / 48 saudáveis (24.6%)
Split: GroupShuffleSplit. Todas as gravações do mesmo sujeito ficam no mesmo conjunto (treino OU teste), prevenindo data leakage

Modelos Treinados

  • SVM (RBF): Support Vector Machine com kernel Gaussiano, class_weight='balanced'
  • Random Forest: Ensemble de árvores de decisão, class_weight='balanced'
  • XGBoost: Gradient boosting com scale_pos_weight para desbalanceamento

Todos otimizados via GridSearchCV com StratifiedKFold(10) e scoring='roc_auc'.

Nota Metodológica: Group-Aware Splitting

O dataset contém múltiplas gravações por sujeito (~6 por pessoa). Se usarmos um split aleatório simples (train_test_split), gravações do mesmo sujeito podem aparecer tanto no treino quanto no teste. Isso causa data leakage: o modelo aprende a reconhecer a voz do indivíduo em vez dos biomarcadores de Parkinson.

Por isso, usamos GroupShuffleSplit, que garante que todas as gravações de cada sujeito fiquem exclusivamente no conjunto de treino ou de teste. Os resultados reportados são honestos e representam a capacidade real de generalização para sujeitos nunca vistos.
