Sobre o Dataset

Fonte: UCI Machine Learning Repository - Parkinsons Dataset
Samples: 195 recordings from 31 subjects (23 with Parkinson's, 8 healthy)
Features: 22 vocal biomarkers extracted from sustained phonations
Distribution: 147 PD samples (75.4%) / 48 healthy (24.6%)
Split: GroupShuffleSplit. Every recording from the same subject stays in the same split (train OR test), preventing data leakage

Modelos Treinados

  • SVM (RBF): Support Vector Machine with a Gaussian kernel, class_weight='balanced'
  • Random Forest: Ensemble of decision trees, class_weight='balanced'
  • XGBoost: Gradient boosting with scale_pos_weight for the imbalance

All tuned through GridSearchCV with StratifiedKFold(10) and scoring='roc_auc'.

Methodological Note: Group-Aware Splitting

The dataset holds several recordings per subject (~6 per person). With a plain random split (train_test_split), recordings from the same subject can land in both train and test. That causes data leakage: the model learns to recognise the individual's voice rather than the Parkinson's biomarkers.

So we use GroupShuffleSplit, which guarantees that every recording from a given subject stays entirely in either the training or the test set. The reported results are honest and reflect real generalisation to subjects never seen during training.
